# Activity-1

## C and C++ Programming

In this activity, I created, compiled, and executed basic programs in both C and C++ using Visual Studio Code. The purpose of this activity was to understand the basic structure of C and C++ programs and learn how to run them using the GCC compiler and terminal.

### 1. C Program – Hello World

I created a C program named `Hello.c` to display the message **"Hello, World!"** on the screen.

The program uses the `stdio.h` header file, which provides the `printf()` function for displaying output. The `main()` function is the starting point of the program. Inside the main function, I used `printf()` to print "Hello, World!" and used `return 0` to indicate successful execution.

The C program was compiled and executed successfully in Visual Studio Code using the terminal, and the output displayed was:

Hello, World!

### 2. C++ Program – Hello World

I created a C++ program named `hello.cpp` to display the message **"Hello, World!"** on the screen.

The program uses the `iostream` header file, which provides input and output functionalities in C++. I used `std::cout` to display the message and `std::endl` to move to the next line. The `main()` function is the starting point of the program, and `return 0` indicates successful execution.

The C++ program was also compiled and executed successfully in Visual Studio Code using the terminal, and the output displayed was:

Hello, World!

### Conclusion

Through this activity, I learned how to create basic programs in C and C++, understand their basic syntax, compile the programs using GCC, and execute them through the Visual Studio Code terminal. I also understood the basic difference between displaying output using `printf()` in C and `std::cout` in C++.
