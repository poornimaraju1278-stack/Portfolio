# Activity-2

## Python and Java Programming

In this activity, I practiced writing, compiling, and executing basic programs using Python and Java. I used Visual Studio Code to create the programs and the terminal to run them and verify their outputs.

### 1. Python Program

I created a basic Python program to display the message **"Hello, World!"**. The program uses the `print()` function to display the output on the screen.

I saved the program as a Python file and executed it through the terminal. The program ran successfully and displayed the expected output:

Hello, World!

Through this program, I learned the basic syntax of Python, how to use the `print()` function, and how to execute a Python program using the terminal.

### 2. Java Program

I also created a basic Java program to display **"Hello, World!"**. The program contains a `main()` method, which is the starting point of execution in Java, and uses `System.out.println()` to display the output.

I compiled the Java program using the Java compiler and then executed it through the terminal. The program successfully displayed:

Hello, World!

Through this program, I learned the basic structure of a Java program, how to compile a Java source file, and how to execute the compiled program using the terminal.
