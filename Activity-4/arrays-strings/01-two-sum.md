# Two Sum

## Problem / Difficulty
Given an array of integers and a target value, find the indices of two numbers that add up to the target.

**Difficulty:** Easy

## LeetCode Link
https://leetcode.com/problems/two-sum/

## Approach
Use two loops to compare each pair of numbers.
If two numbers add up to the target, return their indices.

## Complexity

**Time Complexity:** O(n²)

**Space Complexity:** O(1)

## Notes
- Tested locally with [2, 7, 11, 15], target = 9 → [0, 1].
